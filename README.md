# Credgenics — Litigation Management Platform

Frontend engineering contributions to a production platform for tracking, managing, and organizing litigation cases.

**Role:** Frontend Developer · **Context:** Professional work at Credgenics

[View product overview](https://www.credgenics.com/litigation-management-system)

## Overview

Litigation case management involves keeping multiple cases, their details, and associated activities organized within a shared workflow. As part of the Credgenics team, I contributed frontend features to support these workflows, developing complete features from scratch within the existing application.

## My contributions

- **Case detail screens:** Developed frontend screens and UI elements for viewing and organizing case information.
- **Case filtering:** Built filters to help users narrow case lists and locate relevant cases.
- **In-product guidance:** Added tooltips and contextual instructions to explain interface elements and guide users through workflows.
- **API integration:** Integrated API calls to retrieve and display data within frontend features.
- **Debugging:** Investigated UI and functional issues, traced their causes, and implemented fixes.
- **Quality assurance:** Performed QA, checked feature behavior, and identified and resolved defects.
- **Product collaboration:** Participated in product discussions and Scrum meetings to understand requirements, discuss implementation, and coordinate delivery with the team.

## Engineering scope

My work extended across feature implementation, API integration, debugging, and QA. It combined building new frontend functionality with understanding and extending an existing production application.

The contributions described here were part of a wider team effort; they do not imply ownership of the entire platform.
